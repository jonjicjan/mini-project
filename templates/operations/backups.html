Offline Disaster Recovery Procedure

Instructions for restoring system state from a downloaded archive.

  1. Stop Application Service: Terminate any active Django or Waitress server processes.
  2. Verify Archive Checksum: Ensure the downloaded archive matches your saved SHA-256 integrity hash.
  3. Run Restore Tool: Execute the built-in restore command in the project root: 
    python manage.py restore_backup <path-to-archive.tar.gz>
  4. Safety Guarantee: The restore process automatically creates a recovery backup of the existing database prior to replacement and forces all active user sessions to safely re-authenticate.
